# Third-party licences

Crest Forge bundles three font families, each under the SIL Open Font License 1.1. The files here are the licence texts shipped with the `@fontsource` packages the build takes the fonts from.

| Chakra Petch | Display type, default text-layer font | [chakra-petch-OFL.txt](chakra-petch-OFL.txt) |
| IBM Plex Sans | Body type | [ibm-plex-sans-OFL.txt](ibm-plex-sans-OFL.txt) |
| JetBrains Mono | Numbers | [jetbrains-mono-OFL.txt](jetbrains-mono-OFL.txt) |
